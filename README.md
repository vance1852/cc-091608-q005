# 心脏康复训练安全

该项目统一描述康复处方、居家训练遥测、症状反馈和设备指令。课程开始时引用的处方版本与采集时间均属于临床记录，不能被后续发布覆盖。

`src/contracts.ts` 提供处方、遥测事件和课程安全事件的类型。`fixtures/rehab-session.json` 是一段脱敏课程，包含断连、处方切换和胸闷反馈。

使用 Node.js 22 与 TypeScript 开发，执行 `npm test` 可检查严格类型约束并运行单元测试。

## 模块

- `src/contracts.ts` — 类型契约：处方生命周期、遥测、安全决定、设备指令/确认、求助、复核、安全事件、徽章、封存与课程摘要。
- `src/prescriptions.ts` — 处方注册表：草稿 → 签署 → （撤回）。签署是下发的前提；已签署版本冻结，调整只能发布更高版本；撤回只追加状态。
- `src/safety.ts` — 规则引擎：按事件时间（capturedAt）评估持续超限、恢复速度与症状组合；迟到/乱序/断连补传的数据只走复核证据分支。
- `src/sessions.ts` — 课程服务：一条课程记录承载遥测、决定、指令、确认、求助、复核、徽章与封存；徽章受安全事件门控。
- `src/service.ts` — 门面：撤回处方时向进行中的课程下发停止原因。
- `src/fixture.ts` / `src/replay.ts` — 样例校验解析与回放脚本。

## 安全规则摘要

1. 处方签署后才能下发；开课固定引用当次有效版本，后续发布/撤回不改写该引用。
2. 症状命中停止清单或处方禁忌 → 立即停止；未列出症状 → 谨慎暂停。
3. 心率持续超限（默认 60 秒）→ 暂停；暂停后恢复过慢（默认 120 秒内下降不足 12 bpm）→ 求助并终止；回到区间内 → 可继续。
4. 决定与指令时间一律取数据到达时间；迟到数据绝不倒推实时指令，只补充复核证据。
5. 安全事件未关闭前不能生成完成徽章；设备侧达标徽章仅作记录，不具备临床效力。
6. 原始遥测只能按保留策略封存，患者不能删除；删除请求一律拒绝并留痕。

## 运行

- `npm test` — 严格类型检查 + 单元测试（处方生命周期、版本固定、撤回、持续超限/恢复、徽章门控、封存、迟到数据）。
- `npm run replay` — 回放 `fixtures/rehab-session.json`：胸闷先触发停止、迟到心率只补充复核证据、旧处方不被新版本改写，并打印可追溯到每条安全决定的课程摘要。
