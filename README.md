# 心脏康复训练安全服务（cardiac-rehab-guard）

居家心脏康复的安全裁决服务。患者按**当次有效且经签署的处方**训练；设备的达标徽章、本地缓存的旧区间都不能凌驾于临床安全限制之上。

## 安全不变量

1. **处方签署后才下发**：治疗师用 Ed25519 对规范化处方内容签名（`src/crypto.ts`），验签通过才登记；版本严格递增、内容冻结，篡改/错签一律拒绝。
2. **开课固定版本**：开始训练时把处方版本、签名与内容指纹绑定进课程记录（深冻结快照）。之后发布新版本或撤回都**不改写**进行中/已结束课程；腕表自报的“上周区间”只留痕比对，绝不采用。
3. **撤回语义**：撤回只阻止新课程；对撤回时仍在 `active/paused` 的绑定课程发出带停止原因的停止指令，已终止课程不受影响。
4. **按事件时间评估、按处理时间行动**：心率持续超限、恢复速度、症状组合等判据使用 `capturedAt`；实时指令只基于处理时刻（watermark）前已收到的证据，`issuedAt` 只取服务器时钟。断连补传的迟到数据只生成 `basis=review-only` 决定补充复核，**绝不倒推指令**。
5. **同一课程记录**：遥测、症状、安全决定、设备指令、设备确认、患者求助、治疗师复核、徽章声称、封存清单全部进入同一条 append-only 哈希链（`src/session-log.ts`），任何改动都会被 `verifyChain()` 发现。
6. **安全事件关闭前无完成徽章**：设备徽章声称只留痕；存在未关闭安全事件、课程未正常完成、有效训练时长不足时一律拒绝。红旗症状停止后只有治疗师复核（`submitReview`）能关闭安全事件。
7. **原始遥测只封存、不可删除**：患者侧没有删除入口（`patientRequestsDeletion` 直接拒绝）；`archiveRawTelemetry` 按保留策略密封并记录存储指纹。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/contracts.ts` | 处方、遥测、安全决定、指令、安全事件、复核、徽章等临床契约 |
| `src/crypto.ts` | 规范化 JSON、Ed25519 签名/验签、SHA-256 指纹 |
| `src/prescription.ts` | 治疗师密钥环、处方签发登记、版本冻结、有效期与撤回校验 |
| `src/clock.ts` | 单调时钟（回放用；禁止时钟回退） |
| `src/safety-engine.ts` | 禁忌症状、症状+心率组合、持续超限、恢复速度规则 |
| `src/session-log.ts` | 同一课程的 append-only 哈希链记录 |
| `src/session-service.ts` | 课程状态机、实时评估与指令、迟到证据复核、撤回、求助、复核、徽章、封存 |
| `src/summary.ts` | 课程摘要与「证据→决定→指令→确认→安全事件→复核」追溯 |
| `src/replay.ts` | 回放 `fixtures/rehab-session.json` 并对全部不变量断言 |

## 使用

Node.js 22，TypeScript 严格模式（`strict` + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`）。

```bash
npm install
npm test      # tsc 类型检查 + 26 个单元测试 + fixture 回放断言
npm run replay   # 只看样例课程回放与摘要
```

## 样例课程回放要点（fixtures/rehab-session.json）

- 腕表仍缓存上周 v2 区间（100–140），课程固定引用调药后签署的 v3（95–125），区间不一致被记录；
- `t1` 112 bpm 在 v3 区间内 → continue（若被 09:10 才发布的 v4 上限 110 改写就会误判，这正是禁止追溯改写的原因）；
- `s1` 胸闷（红旗症状）09:08:00 采集、09:08:01 收到 → 立即 **STOP + seek-help**，设备 09:08:20 确认，患者 09:08:40 求助；
- 09:07/09:08:05 的 136/133 bpm 因断连 09:12 才补传，与症状构成持续超限，但课程已停止 → 仅 **review-only** 证据，无实时指令；
- 设备 09:16 自弹达标徽章 → 拒绝（安全事件未关闭 + 时长不足）；
- 09:20 撤回 rx-8：平行课程 rehab-33 被实时停止，rehab-32 不受影响，且不能开新课；
- 复诊复核关闭全部安全事件后课程 `completed`；徽章重试仍因有效时长不足被拒；原始遥测按一年保留策略封存，患者删除被拒。
